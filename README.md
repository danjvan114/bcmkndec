
# BCMKN 文件解密工具


📖 项目说明

这是一个开源项目，用于对您的 bcmkn 文件进行解密。

通常播放器（Player）加载的文件是加密的，需要经过解密后才可以进行编辑，本项目就是解决这个问题的。

📦 提供版本

• HTML 版

• Python 版

##😀 使用方法
将需要抓的播放器在新标签页打开，并按下F12（或CTRL+shift+I）打开开发者工具，点击网络选项卡，在筛选器中输入**bcmkn**，类型为全部，并刷新页面
稍等后即可看到bcmkn文件被加载且显示在控制台，右键点击**在新标签页打开**，通常会自动下载文件到本地，此时再打开解密工具选择此文件即可

文件解密后，请把后缀改为bcmkn（默认产物为json，如果你认为不影响的可以不改）
